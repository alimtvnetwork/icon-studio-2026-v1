# Icon Studio 2026

> Automated multi-product design studio, icon design system, and brand asset repository.

---

## Overview

**Icon Studio 2026** is a unified workspace housing brand identities, vector icons, multi-resolution raster suites, animated marks, and theme tokens for browser extensions and web tools. Every project follows an automated, deterministic directory structure with production-ready SVGs, standard raster icon tiers, and machine-readable design tokens.

---

## Sub-Projects & Branding Suites

The repository hosts 5 distinct sub-projects under [`Projects/`](./Projects/), each structured with its own complete asset suite:

```
Projects/
├── 01-MacroMate/       # Macro automation Chrome extension

```

## Canonical Project Structure

Every design project under `Projects/{Seq}-{PascalCaseProjectName}/` adheres to the following specification:

```
Projects/{Seq}-{PascalCaseProjectName}/
├── README.md                 # Inline GitHub asset showcase
├── favicon.ico               # Multi-resolution project favicon
├── favicon.png               # High-res favicon (256x256)
├── icons-svg/                # Semantic SVG vectors
│   ├── Logo.svg              # Primary full-color vector mark
│   ├── Logo-Dark.svg         # Dark-mode optimized vector mark
│   ├── Logo-White.svg        # Single-color white vector mark
│   └── Logo-Animated.svg     # Optional SMIL looping animation
├── icons-image/              # Raster deliverables & mockups
│   ├── Logo-052.png          # 52x52 toolbar / compact icon
│   ├── Logo-128.png          # 128x128 extension default icon
│   ├── Logo-256.png          # 256x256 medium icon
│   ├── Logo-512.png          # 512x512 high-res application icon
│   ├── Logo-1024-Light.png   # 1024x1024 light background presentation
│   ├── Logo-1024-Dark.png    # 1024x1024 dark background presentation
│   └── Logo-Animated.gif     # Optional animated GIF preview
└── colors-themes/            # Design system tokens
    ├── Palette.md            # Human-readable color swatches (HEX, HSL)
    └── Tokens.json           # Flat PascalCase machine-readable tokens
```

## Design Tokens Specification

Tokens are standardized as flat PascalCase keys in `colors-themes/Tokens.json` for direct ingestion into Tailwind, CSS variables, or design systems:

```json
{
  "Primary": "#7C3AED",
  "PrimaryGlow": "#A78BFA",
  "Secondary": "#4C1D95",
  "Accent": "#F0ABFC",
  "Background": "#FFFFFF",
  "Foreground": "#0F0A1E",
  "Muted": "#F4F1FB",
  "Border": "#E5DEF7"
}
```
