# Logo Creation Instruction

Please instruct Lovable to create a logo for me. The instruction should be saved into memory as well, so it knows how to create a logo. I will give the product name, a little bit of product idea based on the voice, and a sample color and things like that. It would generate the project name first at the root level. So there should be a folder named `Projects`, and inside that it will have `01`, `02`, `03`, etc., project name folders. Inside a project name folder, it would have an `icons-svg` folder, where all icons will be created as SVG. Also, there would be an `icons-image` folder, where the image of the icon would be there — two, three samples. If the icon is required to have a dark and white version, it should make both versions. The other part is to create the colors and themes, and at the end, it should also create the favicon for the website. That should be on the root of the repo. And there should be an MD file that actually uses all these things and displays them on Git. This is how, any time an icon is asked to be created, it should be done.

## Breakdown

1. Inputs (provided by user)

   a. Product name

   b. Short product idea / voice / tone

   c. Sample color(s) or palette hint

   d. Optional: dark/white version requirement

2. Outputs (generated by Lovable)

   a. Project folder under `Projects/`

   b. SVG icons

   c. Raster image samples of icons

   d. Dark and white variants when required

   e. Color and theme tokens

   f. Favicon at repo root

   g. README MD file in the project folder rendering all assets for GitHub preview

## Folder Structure

```

/ (repo root)

└── Projects/

    ├── 01-{ProjectName}/

    │   ├── favicon.ico

    │   ├── favicon.png

    │   ├── README.md

    │   ├── icons-svg/

    │   │   ├── Logo.svg

    │   │   ├── Logo-Dark.svg

    │   │   └── Logo-White.svg

    │   ├── icons-image/

    │   │   ├── Logo-Sample-01.png

    │   │   ├── Logo-Sample-02.png

    │   │   └── Logo-Sample-03.png

    │   └── colors-themes/

    │       ├── Palette.md

    │       └── Tokens.json

    ├── 02-{ProjectName}/

    └── 03-{ProjectName}/

```

Notes:

1. Project folder naming: `{Sequence}-{PascalCaseProjectName}` (e.g. `01-AcmePay`).

2. Sequence is zero-padded two-digit, starting at `01`.

3. All file and folder names use PascalCase where applicable.

## Actionable Items

1. Input Capture

   a. Accept `ProductName`, `ProductIdea`, `VoiceTone`, `SampleColors[]`, `NeedsDarkWhiteVariants` (boolean)

   b. Validate inputs; ask for clarification if any are missing

2. Project Scaffold

   a. Create or detect `Projects/` at repo root

   b. Determine next sequence number (`01`, `02`, ...)

   c. Create `Projects/{Seq}-{PascalCaseProjectName}/`

3. SVG Icon Generation

   a. Create `icons-svg/` inside the project folder

   b. Generate primary `Logo.svg`

   c. If `NeedsDarkWhiteVariants` is true, also generate `Logo-Dark.svg` and `Logo-White.svg`

4. Raster Image Samples

   a. Create `icons-image/` inside the project folder

   b. Generate 2–3 PNG/JPG samples (e.g. on light background, dark background, mockup context)

5. Colors and Themes

   a. Create `colors-themes/` inside the project folder

   b. Produce `Palette.md` (human-readable swatches with HEX/HSL)

   c. Produce `Tokens.json` (PascalCase keys, e.g. `Primary`, `PrimaryGlow`, `Background`, `Foreground`, `Accent`)

6. Favicon

   a. Generate `favicon.ico` and `favicon.png` at repo root

   b. Update `index.html` `` if applicable

7. README Generation

   a. Create `README.md` inside the project folder

   b. Embed all SVGs, image samples, palette swatches, and favicon preview using relative paths so GitHub renders them

   c. Include sections: Overview, Logo Variants, Image Samples, Color Palette, Theme Tokens, Favicon, Usage

8. Memory Persistence

   a. Save this instruction to `.lovable/prompts/02-logo-create.md`

   b. Add an entry to `.lovable/prompts.md` index with triggers (e.g. `create logo`, `make logo`, `logo`)

   c. Update `mem://index.md` Core with a one-liner so future sessions auto-apply

## Database

Not applicable for this task (asset generation only). If a registry of generated logos is later required, request it explicitly.

## Acceptance Criteria

1. `Projects/{Seq}-{PascalCaseProjectName}/` exists with the exact subfolders: `icons-svg/`, `icons-image/`, `colors-themes/`, plus `README.md`.

2. At least one `Logo.svg` exists; if dark/white requested, both `Logo-Dark.svg` and `Logo-White.svg` exist.

3. `icons-image/` contains 2–3 raster samples.

4. `colors-themes/Palette.md` and `colors-themes/Tokens.json` exist; `Tokens.json` uses PascalCase keys.

5. `favicon.ico` (and/or `favicon.png`) exists at repo root and is referenced from `index.html`.

6. Project `README.md` renders all assets correctly when viewed on GitHub (relative paths, no broken links).

7. Instruction saved at `.lovable/prompts/02-logo-create.md` and indexed in `.lovable/prompts.md`.

8. `mem://index.md` Core updated with the logo-creation rule.
