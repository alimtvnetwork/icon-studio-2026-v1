# Strictly Avoid

Hard prohibitions for this project.

- **Mirroring logo spec to mem://**: The full logo creation spec lives ONLY in `.lovable/prompts/02-logo-create.md` and root `plan.md`. Never duplicate it to `mem://` beyond the one-line Core pointer.
- **Overwriting existing project folders**: Always auto-increment sequence. Never overwrite `Projects/01-*` or `Projects/02-*`.
- **Leaving orphaned memory files**: Every file under `.lovable/memory/` must be indexed in `.lovable/memory/index.md`.
- **Splitting plan.md or suggestions.md**: These stay single files, never broken into folders.
