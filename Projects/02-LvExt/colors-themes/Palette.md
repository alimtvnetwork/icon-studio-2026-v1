## Usage
- **Primary → PrimaryGlow → PrimaryDeep** triple-stop gradient for the icon tile and brand surfaces.
- **Foreground (white)** for the L + X mark.
- **Accent (cyan/teal)** reserved for the "extension plug" indicator and active states.
