# GitMap Autonomous Engineering Skill

## Primacy & Mandatory Tools
- Live symbol search: `gitmap aum search "<pattern>" [dir] [--ext <ext>]`
- File finding: `gitmap find "<pattern>"` / `gitmap ff <name>`
- File streaming: `gitmap cat <filepath>`
- Python runner: `gitmap py "<code-or-script>"`
- PowerShell runner: `gitmap ps "<cmd>"`
- Semantic commit & push: `gitmap cpf "<module> - <summary>"` (hyphen-separated only; no colon)
